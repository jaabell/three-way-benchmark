# Local OpenSees preliminary run

Serial OpenSees 3.8.0, build a73b500629148986b3911ebfc61a1b501fe19306, with UMFPACK. Gmsh 4.15.1 generated the smoke mesh of 7,140 quadratic tetrahedra. The run used 12 equal increments, a final gravity multiplier of 27.058142854681905, a 0.1 N residual tolerance, and up to 35 Newton iterations per increment. The final external work differs from elastic energy plus plastic dissipation by 0.0334% of external work. The history describes this workstation pilot and its results should be interpreted separately from the Esmeralda benchmark.
